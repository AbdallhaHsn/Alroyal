# الرويال للتطوير العقاري - النظام المالي والمحاسبي
### Al-Royal Real Estate Development - Financial & Accounting ERP System

نظام مالي ومحاسبي متكامل لإدارة واستعراض بيانات قاعدة البيانات المحاسبية (`RoyalDb`) بدقة عالية وواجهات حديثة تدعم اللغة العربية بالكامل (RTL) مع تصدير وطباعة تقارير مالية معتمدة وفق المعايير المحاسبية.

---

## 🛠 التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):**
  - React 18 + TypeScript + Vite
  - Tailwind CSS + Lucide React Icons
  - خط Cairo العربي المعتمد ودعم RTL كامل
  - SheetJS (XLSX) للتصدير المحاسبي المنسق

- **الواجهة الخلفية (Backend API):**
  - Node.js + Express
  - `mssql` (اتصال مباشر بقاعدة Microsoft SQL Server عبر Windows Authentication)
  - CORS + RESTful API Architecture

---

## 🚀 المميزات والتقارير المالية

1. **كشف الحسابات العامة والتحليلية (General Ledger):**
   - العرض التفصيلي للقيود والسندات مع التاريخ، نوع السند، البيان، المدين، الدائن، والرصيد التراكمي.
   - العرض التجميعي السريع حسب الحسابات الفرعية مع الحركات التراكمية.
   - مطابقة الأرصدة الافتتاحية والختامية بدقة متناهية.

2. **كشف حساب الحسابات الفرعية (Subsidiary Ledger):**
   - بحث فوري وتصفية حسب كود الحساب أو اسمه.
   - كشف تفصيلي بحركات العميل أو المورد أو الحساب الفرعي.

3. **ميزان المراجعة الشامل (Trial Balance):**
   - ميزان بالمجاميع والأرصدة.
   - إمكانية طي وتوسيع الحسابات بضغطة زر.

4. **الطباعة والتصدير:**
   - طباعة تقارير مالية مصممة خصيصاً لمقاس A4 بدون أي قص في الأعمدة أو البيانات.
   - تصدير كشوف الحسابات إلى Excel منسق جاهز للتقديم مع ترويسة الشركة الرسمية.

## 💻 طريقة التشغيل محلياً

### 1. المتطلبات:
- Node.js (الإصدار 18 أو أحدث)
- Microsoft SQL Server وقاعدة بيانات `RoyalDb`

### 2. التشغيل السريع:
يمكن تشغيل النظام مباشرة عبر النقر المزدوج على:
```bat
start.bat
```

### 3. أو عبر موجه الأوامر (Terminal):
**الخادم (Backend):**
```bash
cd server
npm install
node index.js
```

**تطبيق الويب (Frontend):**
```bash
cd client
npm install
npm run dev
```

- رابط النظام: `http://localhost:3000`
- رابط الـ API: `http://localhost:5000/api/health`
